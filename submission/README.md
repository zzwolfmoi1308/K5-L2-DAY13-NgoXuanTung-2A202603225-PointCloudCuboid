# Bảng A và phiếu tự kiểm

Thư mục này chứa hai file do lệnh sinh ra, được commit vào repo của bạn:

| File | Lệnh sinh ra |
|---|---|
| `D13-<MSSV>-bangA.csv` | `python scripts/lab.py report` (hoặc `sync`) |
| `D13-<MSSV>-tukiem.csv` | `python scripts/lab.py selfcheck` (hoặc `sync`) |

Không sửa tay, không lưu lại bằng Excel: muốn đổi số thì sửa cuboid trên CVAT, Save, rồi chạy lại `python scripts/lab.py sync` ([../RULES.md](../RULES.md)). Chỉ để file của mã số của bạn ở đây.
